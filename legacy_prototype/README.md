# VolunteerMatch AI — Community & NGO Volunteering Platform

## Overview
**VolunteerMatch AI** is an interactive web application connecting volunteers with NGOs and community organizations using explainable AI-assisted matching, conflict-free scheduling, task management, and verified service certificates.

## Project Structure
- `index.html` — Dual-POV Login/Onboarding screen (Volunteer & NGO Organizer), Discover Drives grid, My Schedule & Tasks view, Impact & Certificate portal, and NGO Organizer dashboard.
- `styles.css` — Custom typography and print-ready styles for generating PDF/printable Certificates of Community Service.
- `app.js` — Explainable AI matching engine, schedule clash detector, localStorage state persistence, NGO opportunity publisher, and dynamic certificate generator.

## How to Run
1. Extract the ZIP archive.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
3. Use the **Switch Role / Logout** button in the top navigation bar to switch between the **Volunteer POV** and **NGO Organizer POV**.
